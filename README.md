A pre-token protocol radar and valuation dashboard for the make.fun token-radar-01 bounty ($1,325 USDC).

## Overview
- Identifies protocols tracking TVL with no recorded token.
- Ranks them by estimated launch valuation and provides step-by-step farming guides.
- Completely offline static dashboard with zero network dependencies.
